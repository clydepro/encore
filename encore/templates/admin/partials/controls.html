{# The five transport buttons (SAPRS 8.8). Each is a form, not a link, because they change something and a GET that mutates is the kind of thing a prefetcher gets wrong. Each names the panel it belongs to in its own URL, so the answer comes back as the region that asked rather than as somebody else's markup — the one piece of wiring that lets the dashboard and the queue screen share both the buttons and the action routes without either of them guessing. A browser without JavaScript gets a 303 to the dashboard instead of a fragment, which is the same bargain `POST /queue` strikes with a phone whose script never loaded (SAPRS 13.2). #}
