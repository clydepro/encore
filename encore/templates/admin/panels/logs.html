{# The appliance's own records, newest first (AIG 14's "Logs", SAPRS 12.8's discipline). This is a *tail*, and it says so: the complete record is in the journal (`journalctl -u encore`), and what is here is the last few hundred lines of the process's memory, which is the part an operator wants while standing next to the box at a party. The number kept is printed so the absence of an older line is not mistaken for the absence of an older event. What a line can never contain is a client. No address, no user agent, no query that would let a question be asked about one phone rather than about the appliance — `encore/services/logging_service.py` redacts the fields that could, and the absence of a filter box here is that rule made visible (ADR-007). Refreshed by `encore:change` like every other admin region. A log page on a timer would be the most predictable request pattern on the network and the least necessary: the events that make a log line are the same events that make the frame. #}
