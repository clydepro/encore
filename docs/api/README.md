# API Reference

Status: **outline**. There is no HTTP surface yet — the API arrives with
milestone 11 (FastAPI) and milestone 13 (SSE) in AIG Chapter 21. This page is
the contract those milestones must fill in, not a description of what exists.

## Conventions (fixed by SAPRS Chapter 10 and AEP 21)

- JSON API is versioned under `/api/v1/...`.
- Additive changes only within a major version; removals need a major bump and
  migration notes in the changelog.
- Errors use a consistent envelope: `{"error": {"code", "message", "details"}}`,
  with codes documented per endpoint.
- Timestamps are RFC 3339 in UTC; durations are milliseconds in integers.
- Guest endpoints require no authentication and never accept or return guest
  identity (ADR-007).
- Administrative endpoints require an authenticated session and are separated by
  path prefix as well as by authorisation.
- HTML fragment endpoints for HTMX are distinct from the JSON API; a fragment is
  not an API.
- OpenAPI is generated by FastAPI and published from this tree once the app
  exists — no hand-maintained schema.

## Planned surface

### Guest

| Method | Path | Purpose |
| ------ | ---- | ------- |
| `GET` | `/` | Now Playing shell |
| `GET` | `/search?q=` | Artist/album/song search (FTS5) |
| `GET` | `/artists`, `/artists/{id}` | Browse |
| `GET` | `/albums`, `/albums/{id}` | Browse |
| `POST` | `/api/v1/queue` | Queue a song (FIFO, duplicates allowed) |
| `GET` | `/api/v1/queue` | Up Next |
| `GET` | `/api/v1/playing` | Now Playing + progress |
| `GET` | `/events` | SSE stream |
| `GET` | `/qr` | Onboarding poster for the current network |

### Administrator

| Method | Path | Purpose |
| ------ | ---- | ------- |
| `POST` | `/admin/login` | Authenticated session start |
| `GET` | `/admin/dashboard` | Health, queue, statistics |
| `POST` | `/admin/playback/{command}` | pause, resume, skip, stop |
| `DELETE` | `/api/v1/queue/{id}` | Remove a queue entry |
| `GET` | `/admin/health` | Component health |
| `GET` | `/admin/statistics` | Runtime statistics |
| `GET` | `/admin/logs` | Structured log tail |
| `GET` | `/admin/configuration` | Read-only configuration summary (SAPRS 12.3) |
| `POST` | `/admin/library/reload` | Swap to a newly published library (ADR-006) |

## Events (SSE payloads)

`SongQueued`, `SongStarted`, `SongFinished`, `QueueAdvanced`,
`PlaybackRecovered`, `LibraryReloaded`, `BuildCompleted`, `HealthChanged` — the
same vocabulary as the internal Event Bus (AIG 8), serialised without HTTP
concepts leaking into the domain.

## Latency expectations

Search < 100 ms, queue mutation < 50 ms, navigation fragment < 200 ms, SSE
propagation < 1 s (SAPRS 1.8). Each endpoint page will record measured numbers
once the benchmarks in `tests/performance/` exist.

## Editing this directory

- One page per resource group; generated pages live in `generated/` and are
  ignored by `tools/check_links.py`.
- Every documented response shape needs an example and a schema test.
- Breaking changes update this page and `CHANGELOG.md` in the same PR.
