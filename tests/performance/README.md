# tests/performance

Measures the SAPRS 1.8 targets rather than asserting them casually:

| Operation              | Target (p95) |
| ---------------------- | ------------ |
| Search                 | < 100 ms     |
| Queue operation        | < 50 ms      |
| HTMX navigation        | < 200 ms     |
| Playback start         | < 250 ms     |
| SSE state propagation  | < 1 s        |

Guidance:

- Use a representative library (~15,000 songs) generated by
  `tests/support/media.py` (placeholder until milestone 3).
- Record with `time.perf_counter`, report p50/p95/p99, and fail on p95.
- Measure before optimizing (AEP 14); a green benchmark is documentation.
- These tests carry the `performance` marker and only run with `--run-slow`
  (scheduled workflow), never in the per-commit gate.
