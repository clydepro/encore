# assets/

Source material for shipped visuals — things that are edited by hand rather
than generated by the Library Builder.

Planned contents:

- `logo/` — Encore wordmark in SVG (any size) and PNG (512 px for installers).
- `qr/` — QR poster templates used for guest onboarding (SAPRS 9.x, ADR-007).
- `icons/` — device/browser touch icons referenced by `encore/static/`.
- `sounds/` — optional UI cues; silence is the default and must stay the default
  (ADR-008: the music is the centre of attention).

Not welcome here: album artwork or anything derived from a user's library. That
is Builder output and belongs in the artwork cache (SAPRS 5.6).

Licensing note: artwork in this directory is MIT-licensed along with the code
unless a file states otherwise, to keep distribution simple (SAPRS 15.15).
